HOSTNEIL WEBSITE STARTER
========================

Included pages:
- index.html        Homepage
- hosting.html      Web hosting service and proposed packages
- vps.html          VPS service and quote request
- pricing.html      Pricing overview
- order.html        Manual order request form
- contact.html      Contact page
- terms.html        Terms template
- privacy.html      Privacy template
- refund.html       Refund template
- assets/style.css  Responsive styling
- assets/script.js  Mobile navigation and form behavior

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in a browser.
3. For best testing, upload the whole folder to a static web host or run a local static server.

BEFORE PUBLISHING — REQUIRED
1. Replace YOUR-SUPPORT-EMAIL@example.com in contact.html.
2. Configure the email recipient in assets/script.js.
3. Add your real WhatsApp number and official payment instructions.
4. Verify every plan price, feature, provider permission, renewal price, and refund term.
5. Legal pages are starter templates, not legal advice. Customize them.
6. The order/contact forms use mailto and DO NOT save orders to a database. For reliable production order handling, connect a backend or a form service.
7. Do not collect payment PINs or passwords.
8. Do not advertise features your reseller provider does not include.
9. Connect a real domain and configure DNS/SSL.

MANUAL ORDER FLOW
Customer submits the form -> email draft opens -> customer sends it -> HOSTNEIL manually confirms price and availability -> verify payment -> provision from upstream provider -> send access details securely.

This is a front-end starter website, not a complete billing panel or hosting provisioning system.
